Pipeline Komputasi Egress Recording, Transcoding, dan HLS Streaming
Mekanisme Siaran Langsung Sidang Terbuka & Pengarsipan Digital Resmi • Platform HUDANG
SPEC-MEDIA-01 • Egress & HLS
1. Media Source
LiveKit Room Tracks
• Track video VP8/H.264 & audio Opus dari semua peserta.
• Egress composite recorder me-render tata letak grid rapat otomatis.
• Watermark resmi Sekretariat DPRD Jawa Barat tersemat.
→
2. Transcoding Engine
FFmpeg Live Transcoder
• Transcode real-time ke format H.264 AAC.
• Segmentasi file HLS (.m3u8 index & .ts segments 4 detik).
• Ekspor simultan berkas rekaman master MP4 ke penyimpanan volume host.
→
3. Distribusi Publik
HLS Web Player / CDN
• Siaran langsung diputar di Portal Publik HUDANG via HLS.js.
• Distribusi RTMP ke kanal YouTube resmi Humas DPRD Jabar.
• Klien publik dapat menonton tanpa membebani server SFU utama.
Penyimpanan Rekaman: Tersimpan pada volume permanen `/recordings` dengan retensi arsip minimum 5 tahun sesuai regulasi kearsipan.
Bitrate Siaran: 1080p @ 3500 kbps
